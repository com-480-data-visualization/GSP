# Setup

The website for our project is built using Vite and React. To set up the project, ensure you have Node.js installed on your machine. You can download it from [here](https://nodejs.org/).

Inside this directory, run the following command to install the dependencies:

```bash
npm install
```

# Development

To start the development server, run:

```bash
npm run dev
```

# Deployment

To deploy the project to GitHub Pages, run the following command:

```bash
npm run deploy
```

After the build has finished, the website should be available at [https://com-480-data-visualization.github.io/GSP/](https://com-480-data-visualization.github.io/GSP/).
